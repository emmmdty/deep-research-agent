## Findings

### 1. Conceptual Foundations of Agents

The concept of "Agent" originates in philosophy, describing an entity possessing desires, beliefs, intentions, and the ability to take action. In artificial intelligence, this concept has been extended to describe intelligent "agents" characterized by autonomy, reactivity, and interactivity. An agent is fundamentally defined as an entity capable of perceiving its environment and taking action. Historically, reinforcement learning (RL)-based intelligent systems dominated the field, with agents typically assigned simple, well-defined tasks with constrained environmental interaction.

### 2. LLMs as the Technical Foundation for Modern Agents

Large Language Models (LLMs) have emerged as a breakthrough technical solution for AI agents, introducing a new deep learning paradigm. LLMs demonstrate exceptional potential in reasoning and planning, aligning with human expectations for agents capable of perceiving surroundings, making decisions, and taking actions in interactive environments. LLMs have been successfully utilized as autonomous agents for automatic task execution due to their planning and reasoning capabilities. However, LLMs are optimized for language generation rather than tool use during training or alignment, which limits their effectiveness as agents. The inherent statelessness of LLMs poses a critical challenge, hindering agents from maintaining logical consistency across complex, multi-step tasks and precluding learning from prior interactions, often resulting in recurring reasoning errors.

### 3. LLM Agent Architecture

LLM agents address the lack of autonomous interaction capabilities of LLMs by integrating three key modules—memory, planning, and tool use—around the LLM core. The LLM core acts as the central processing unit, but supporting components transform a simple language model into a sophisticated agent capable of complex, multi-step interactions. The architecture requires seamless integration between the language model core and its supporting systems to achieve truly autonomous behavior.

LLM agents differ from chatbots in that they autonomously plan multi-step workflows, retrieve contextual information from integrated systems, and complete actions without constant human guidance. Core components include reasoning loops, memory systems, and tool integration. The main types of LLM agent architectures include routing-focused, resource-invoking, recall-enhanced, and layered evaluation architectures. A key part of how LLM agents work is the response cycle: after completing a task, the agent checks the result against established standards or user feedback.

### 4. LLM-Based Multi-Agent Systems

LLM-based multi-agent systems (MAS) are considered a promising pathway toward realizing general artificial intelligence equivalent to or surpassing human-level intelligence. A survey synthesizes a general structure of LLM-based MAS encompassing five key components: profile, perception, self-action, mutual interaction, and evolution. The unified agent framework comprises these five essential modules, where Profile addresses how agents are created with personalized characteristics, Perception addresses how agents acquire knowledge from the environment, Self-Action addresses memory utilization and reasoning/planning, Mutual interaction addresses inter-agent communication, and Evolution addresses self-improvement.

MAS are complex systems composed of multiple interacting intelligent agents, capable of simulating social interactions and teamwork. The core advantage of MAS lies in distributed decision-making and problem-solving capabilities. Agents in MAS can interact by simulating real-world collaboration patterns such as cooperation, competition, and hierarchical organization. The process underscores the importance of inter-agent communication, reasoning with knowledge and experience, and evolution within the interactive environment. Applications span problem-solving and world simulation, including industrial engineering, scientific experimentation, embodied agents, gaming, and societal simulation. However, multi-agent systems inherit all limitations of individual LLMs plus new failure modes that emerge from collaboration itself.

### 5. AI Agent Frameworks and Tools

**LangChain** is a popular open-source framework for building applications with LLMs, not tied to one specific model provider. It connects any LLM to company data, external APIs, and other tools, with compatibility across OpenAI, Anthropic (Claude), Google (Gemini), and open-source models. LangChain enables multi-step workflows via Chains, provides detailed control over RAG processes, and includes advanced tools like LangGraph for building complex agents. It has the largest active development community among AI agent frameworks. However, it is harder to learn, requires managing all moving parts, and total cost is usually higher due to LLM API calls, hosting, vector databases, and engineer salaries.

**LlamaIndex** is compatible with OpenAI, Anthropic, and open-source LLMs, integrating smoothly with LangChain to improve agent capabilities for scalable, intelligent automation. It is strong for the specialized use case of RAG.

**AutoGen** is Microsoft Research's multi-agent conversation framework. In late 2024, it split: Microsoft continued an AutoGen v0.4+ rewrite, while the community forked the v0.2 lineage as AG2. AutoGen v0.4 is a complete redesign featuring an asynchronous, event-driven architecture with three layers: core, agent chat, and first-party extensions. It supports asynchronous messaging, modular components, observability, scalable distributed networks, cross-language support, and full type support. AutoGen is now in maintenance mode, will not receive new features, and is community managed going forward. It is best for research-style agent conversations, code-execution agents, and group chat patterns.

**OpenAI Assistants API** is a framework that helps developers build AI applications using OpenAI's models like GPT-4. It provides Persistent Threads (managing conversation history), built-in tools including Code Interpreter and Knowledge Retrieval, and supports Function Calling. The API is limited to OpenAI's ecosystem with high vendor lock-in, has lower flexibility tied to OpenAI's roadmap, and uses pay-as-you-go pricing for all services. It is simpler for basic bots but offers less control compared to LangChain.

### 6. Agent Evaluation and Benchmarks

LLM agent evaluation benchmarks include coding and software engineering tasks such as resolving GitHub issues (SWE-bench), scientific data analysis programming (ScienceAgentBench), reproducing research (CORE-Bench, PaperBench), and interactive coding in apps (AppWorld). SWE-bench Verified is considered the industry gold standard for programming agent evaluation, using real GitHub issues with bug-fixing tasks and test-based scoring. Performance on SWE-bench Verified improved from 40% in early 2024 to over 80% by early 2025.

E2EDevBench is a benchmark built by dynamically scraping high-quality recent open-source projects from PyPI, covering 50 projects from Q1 2024 to Q1 2025 to avoid data leakage risk. In WebArena testing, GPT-4 achieved only 14.9% success rate, with GPT-4o showing no significant improvement. Gaps in web automation (WebArena) and general computer use (OSWorld) underscore challenges of hallucination, long-horizon planning, robustness, and safety that must be addressed for practical reliability.

### 7. Enterprise Adoption and Market Data

In enterprises that have deployed AI agents, 66% reported productivity improvements and 57% reported faster decision-making. The global AI agent market is projected to reach $47.1 billion by 2030. The Chinese market for AI agents is expected to exceed ¥8.5 billion in 2025, with IDC data showing the 2024 China AI agent software market exceeded ¥5 billion. Deloitte predicts that by 2027, 50% of enterprises using generative AI will deploy AI agents. According to Gartner, by 2028, 33% of enterprise software applications will include AI agents, up from less than 1% in 2024. IBM Think Insights similarly projects 33% of enterprise software applications will include agentic AI by 2028.

More than half of surveyed respondents are using AI agents in production environments, with the vast majority planning deployment in the near future. Primary use cases include information research and summarization, personal productivity enhancement, and customer service. The report emphasizes the importance of tracking and observability tools and human oversight in controlling AI agent risks, with performance quality identified as the biggest obstacle to deployment.

### 8. GitHub Copilot Adoption and Impact

GitHub Copilot has become the most widely adopted AI developer tool, with 90% of Fortune 100 companies using it. It has over 15 million users (4x growth in one year), 1.3 million paid users (30% quarterly growth), and over 50,000 organizations using it. GitHub's research found developers code up to 51% faster when using Copilot for certain tasks. Copilot has an 88% code retention rate, and enterprise deployments show an 84% increase in successful builds. However, 29.1% of Python code generated by Copilot contains potential security weaknesses requiring review. Accenture's randomized controlled trial found an 8.69% increase in pull requests per developer, an 11% increase in pull request merge rates, and 90% of developers reported feeling more fulfilled with their jobs.

### 9. AI Agent Applications in Healthcare and Industry

AI agents in healthcare show potential promise, particularly in new drug development where early research time can be shortened by 75%-90% (from target identification to lead compound stage). The ability to fuse heterogeneous, multi-intent information from diverse clinical sources is fundamental to building reliable decision-making systems in healthcare intelligence. In industry applications, a China Telecom case reduced labeling work for million-level unstructured data from weeks to hours. Other documented applications include a Chongqing public security "digital police officer" that processed over 60,000 tasks with nearly 90% reduction in fraud rates and six-fold efficiency improvement.

### 10. Agent Limitations and Challenges

Current large models show significant deficiencies in task decomposition and planning capabilities; relying on models for independent thinking and autonomous planning paths is insufficient to ensure agent reliability and task success rates. LLMs struggle at implicit reasoning, including composition, with substantial evidence only in first-hop reasoning. The "compositionality gap" does not decrease with scale. GPT-4 struggles at implicitly comparing entity attributes despite knowing them perfectly. Challenges remain in long-horizon planning, hallucination mitigation, and safe deployment for agents to achieve practical reliability.
