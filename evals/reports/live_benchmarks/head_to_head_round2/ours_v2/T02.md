## Executive Summary
- RAG (retrieval-augmented generation) is an AI architecture that combines information retrieval with large language model generation. [1]
- A RAG system retrieves relevant documents or data from an external knowledge source at the time a query is made and provides that retrieved context to the LLM before generating a response. [1]
- RAG is an AI architecture pattern that connects large language models to external knowledge sources at inference time, enabling those models to generate accurate, context-aware responses that go beyond their static training data. [2]
- A RAG system retrieves relevant documents from an external database in response to each user query and injects that content into the LLM prompt before generation. [2]
- RAG is a technique that enables large language models (LLMs) to retrieve and incorporate new information from external data sources. [3]
