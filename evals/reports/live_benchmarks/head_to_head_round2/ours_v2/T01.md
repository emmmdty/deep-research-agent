### LLM Agents: Capabilities and Limitations
Large language models (LLMs) have achieved success in acting as agents that interact with environments through tools such as search engines.  LLM agents are autonomous or semi-autonomous systems that use LLMs to reason, plan, and act. [47]  LLM agents operate in dynamic, interactive environments, reasoning, making plans, executing tools, leveraging memory, and collaborating with humans or other agents.  LLM agents significantly extend the capabilities of standalone LLMs, empowering them to interact with external tools (e.g., APIs, functions) and complete various tasks in a self-directed fashion. [33]  However, LLMs are optimized for language generation instead of tool use during training or alignment, limiting their effectiveness as agents. [12]  Through the acquisition of vast amounts of Web knowledge, LLMs have shown potential in human-level intelligence, leading to a surge in research on LLM-based autonomous agents. 
### Evaluation of LLM Agents
Evaluating LLM agents is more complex than evaluating LLMs in isolation because LLM agents operate in dynamic, interactive environments. [47]  LLM agents are inherently probabilistic and behave dynamically, unlike traditional software which focuses on deterministic and static behavior. [48]  The evaluation of LLM agents is at the intersection of natural language processing (NLP), human-computer interaction (HCI), and software engineering. [48]  A survey proposes a two-dimensional taxonomy of LLM agent evaluation organized by evaluation objectives (what to evaluate) and evaluation process (how to evaluate).  The Evaluation Objectives dimension includes Agent Behavior, Agent Capabilities, Reliability, and Safety and Alignment. [49]  Agent Capabilities include tool use, planning and reasoning, memory and context retention, and multi-agent collaboration.  Agent Behavior focuses on outcome-oriented aspects such as task completion and output quality, capturing how well an agent meets end-users' expectations. [49]  Reliability assesses whether an agent behaves consistently for the same input and robustly when input varies or the system encounters errors. [49]  Safety and Alignment evaluates the agent's trustworthiness and security, including fairness, compliance, and the prevention of harmful or unethical behaviors.  The Evaluation Process dimension distinguishes between static evaluation, where agents respond to fixed inputs, and interactive assessment, where agents engage with users. [49]  Task completion is a fundamental objective of agent evaluation, assessing whether an agent successfully achieves the predefined goals of a given task. [51]  Task completion is commonly quantified using metrics such as Success Rate (SR), which can also be referred to as Task Success Rate or Overall Success Rate.  Output quality refers to the characteristics of responses by an LLM agent, encompassing aspects such as accuracy, relevance, clarity, coherence, and adherence to agent specifications or task requirements. [52]  An agent may complete a task yet still deliver a subpar user experience if the interaction lacks qualities such as accuracy, relevance, clarity, coherence, and adherence to specifications. [52]  Agent behavior refers to the overall performance of the agent as perceived by a user, treating the agent as a black box, encompassing aspects such as task completion, output quality, latency, and cost.  Task completion is applied across a wide range of LLM agent evaluation domains and benchmarks, including coding and software engineering tasks such as resolving GitHub issues (SWE-bench), scientific data analysis programming (ScienceAgentBench), and web navigation (WebArena). [52]  Unlike evaluating language models, agent assessment involves complex tasks without single correct answers. [53]
